# Notes on web/

Files in `web/` carry no comments (HTML, CSS or JS): they're served as is, and pro's `deploy.sh` refuses to deploy a `web/` that has any. The notes that would be comments live here instead, one file per source file, organized by the code's sections and functions. This folder is never deployed.

- [app.js.md](app.js.md)
- [style.css.md](style.css.md)
- [theme.js.md](theme.js.md)
- `web/shop.css` is empty in the starter; see [customizing.md](../customizing.md).
