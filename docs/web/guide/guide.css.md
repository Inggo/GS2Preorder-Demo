# web/guide/guide.css

The owner guide page (`web/guide/index.html`). Demo repo only. It uses `../style.css` for the default theme's colors, fonts and footer, then lays out a long-form reading page.

- **`.guide-toc`**: the table of contents, a block on phones and a sticky column on wide screens.
- **`.steps`**: numbered instructions, with a bit more room between lines.
- **`.guide-flow`**: the "How it works" section's three cards.
- **`.shot`**: GitHub screenshots. The red boxes are drawn into the images themselves, not by CSS.
